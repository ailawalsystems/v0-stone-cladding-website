                            QUICK START GUIDE
================================================================================

1. CONFIGURE PROVIDER:
   Admin → AI Assistant → Providers tab
   → Expand provider (e.g., OpenAI)
   → Enter API key
   → Save

2. SELECT MODEL:
   Admin → AI Assistant → Model Config tab
   → Select Provider
   → Select Model
   → Adjust parameters (temperature, etc.)
   → Save Configuration

3. ENHANCE NLP:
   Admin → AI Assistant → NLP Settings tab
   → Toggle features on/off
   → Select language
   → Configure text processing

4. ADD KNOWLEDGE:
   Admin → AI Assistant → Knowledge Base tab
   → Upload documents
   → Auto-indexed for retrieval
